# Vertex Mail

**Vertex Mail** is a free, **open-source, browser-based IMAP email client** written in PHP and JavaScript. It provides a modern, desktop-like user interface for managing standard server-side email. 

Because it is open-source and highly stable, Vertex Mail is heavily utilized by global web hosting platforms, educational institutions, and self-hosted environments. The software is also distributed as a native Debian package (** .deb **), making it straightforward to install and update on Debian-based systems like Ubuntu.

### Core Capabilities

* **Full IMAP/SMTP Integration:** Vertex Mail connects directly to your mail server. Because it caches files in real-time, your folders, read/unread statuses, and structures stay instantly synced across external apps like Outlook or Apple Mail.
* **Application-Like Interface:** Utilizing AJAX, the web application mimics standard desktop operating software, allowing you to drag-and-drop messages, compose rich-text (HTML) or plain-text mail, and view threaded conversation layouts.
* **Extensibility:** Administrators can install hundreds of custom templates, skins, and functionality additions using Vertex Mail's robust Plugin API. 
* **Contact & Management Tools:** Includes a built-in address book supporting standard vCard formats and global business directory queries over LDAP.
* **Security Standards:** Out-of-the-box support for secure TLS server protocols, integrated PGP email encryption, and strict cross-site scripting (XSS) protections.

### System Requirements

To self-host Vertex Mail via the .deb package or manually on your own virtual private server (VPS) or dedicated machine, you need:

* **Server Framework:** Apache, Nginx, Lighttpd, or IIS web server configurations.
* **Backend Runtime:** PHP 8.1 or higher.
* **Database Layer:** MySQL, MariaDB, PostgreSQL, or SQLite
